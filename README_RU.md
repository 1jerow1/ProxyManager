# Proxy Manager (Windows)

Небольшой GUI для запуска sing-box через TUN: через прокси идут либо только выбранные программы, либо весь компьютер.

## Что умеет
- Подключение через SOCKS5 или HTTP-прокси (IP, порт, логин, пароль).
- Вставка строки прокси целиком: `host:port:логин:пароль`, `логин:пароль@host:port` или `socks5://логин:пароль@host:port` — поля заполнятся сами.
- Проверка прокси перед запуском: сервер недоступен, неверный порт или тип прокси, неверный логин или пароль — сообщается сразу, а не после запуска туннеля.
- Три режима: «Выбранные» (через прокси только отмеченные программы), «Все, кроме выбранных» (через прокси весь компьютер, отмеченные программы — напрямую) и «Весь компьютер».
- Выбор программ, которые работают через прокси: Claude, Google Chrome, VS Code, Hermes и любые другие программы, которые вы добавите: они показываются в окне и запоминаются. Программы узнаются по полному пути, а не по имени файла.
- Kill switch (в режиме выбранных программ): если sing-box упадёт, выбранные программы остаются без интернета, а не уходят в сеть напрямую.
- Запуск, остановка и переподключение sing-box одной кнопкой.
- Отслеживание sing-box: если он упадёт, программа покажет причину из лога и уведомление в трее.
- Проверка внешнего IPv4 через api.ipify.org: отдельно для выбранных программ и для остальных, а в режиме всего компьютера — один адрес.
- Сворачивание окна в системный трей. Цвет значка показывает состояние: серый — отключено, жёлтый — идёт подключение, зелёный — подключено.
- Раздельное сохранение настроек HTTP и SOCKS5 в settings.json с переключением профилей.

## Требования
- Windows 10/11 x64.
- Python 3.11 или новее.
- Права администратора для TUN/маршрутов.
- Windows amd64 версия sing-box.
- SOCKS5- или HTTP-прокси с доступом из вашей сети. HTTP-прокси не передаёт UDP; SOCKS5-серверу для UDP-зависимых приложений нужна поддержка UDP ASSOCIATE.

## Установка
1. Распакуйте архив в `D:\Oleg\ProxyManager` или другую папку без ограничений доступа.
2. Скачайте официальный Windows amd64 архив sing-box: https://github.com/SagerNet/sing-box/releases
3. Поместите `sing-box.exe` в `bin\sing-box.exe`.
4. Откройте PowerShell в папке проекта:
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python main.py
   ```
5. При запросе UAC разрешите запуск от имени администратора. Программа с правами администратора запускается через `pythonw.exe`, без отдельного окна консоли.
6. Выберите тип прокси, введите IP/домен, порт, логин и пароль. Можно вставить строку прокси от провайдера целиком в поле «Сервер» — она разберётся на поля, когда вы перейдёте к другому полю.
7. Выберите режим. В режимах «Выбранные» и «Все, кроме выбранных» отметьте нужные программы. Нажмите «Подключить».
8. После подключения строка IP покажет два адреса: «Выбранные программы» (адрес прокси) и «Остальные программы» (ваш обычный адрес). В режиме «Весь компьютер» она покажет один адрес — адрес прокси.
9. TUN направляет трафик выбранных программ через прокси автоматически. Не задавайте отдельный прокси в настройках Chrome. Для HTTP-профиля у выбранных программ блокируются IPv6 и UDP, так как HTTP-прокси поддерживает только TCP.

## Игры Steam (Dota 2, CS2)
Windows не умеет направлять трафик по программам, поэтому весь трафик компьютера проходит через адаптер `singbox`, а sing-box уже решает, что отправить через прокси, а что выпустить напрямую. Программы не из списка выходят в интернет с вашим IP, но их пакеты всё равно обрабатывает sing-box. Обычным программам это незаметно, а онлайн-играм — заметно: растёт и скачет пинг, а Dota может неверно оценить пинг до регионов, потому что Steam перед матчем разом пингует сотни серверов.

Галочка «Игры Steam (Dota 2, CS2) напрямую, мимо туннеля» (включена по умолчанию) убирает серверы Valve из туннеля совсем: Windows отправляет трафик к ним напрямую, как будто Proxy Manager не запущен.
- Работает в обоих режимах, в том числе в режиме «Весь компьютер» — иначе с HTTP-прокси Dota вообще не работала бы, а с SOCKS5 играла бы с пингом до прокси. Серверы Valve при этом видят ваш настоящий IP.
- Исключаются сети Valve (AS32590) и текущие реле Steam Datagram Relay от других хостингов — их список программа берёт у Steam при каждом подключении и сохраняет в `logs\valve-relays.json` на случай, если Steam не ответит.
- Сайты Steam (магазин, сообщество, dota2.com) работают на серверах Akamai и в исключение не входят: в выбранном браузере они по-прежнему открываются через прокси.
- Изменение применяется при подключении: если прокси уже подключён, нажмите «Переподключить».

## Режим «Все, кроме выбранных»
Через прокси идёт весь компьютер, как в режиме «Весь компьютер», а программы, отмеченные в списке, ходят в интернет напрямую, с вашим настоящим IP.
- В этом режиме список называется «Напрямую, мимо прокси» и хранит свои галочки отдельно от режима «Выбранные»: одна и та же программа может быть отмечена в одном режиме и не отмечена в другом.
- При первом запуске в исключения сами добавляются **Discord** и **Dota 2**, если они установлены. Discord добавляется папкой `%LOCALAPPDATA%\Discord` (он запускается из папки с номером версии), Dota 2 — папкой игры из библиотеки Steam. Если убрать их из списка крестиком, сами они больше не вернутся.
- Правило для исключений стоит раньше запретов HTTP-прокси, поэтому у программ из списка работают UDP и IPv6: звонки в Discord и игра в Dota 2 идут как без прокси. У остальных программ с HTTP-прокси UDP отклоняется.
- Сам клиент Steam в исключения не входит: магазин и загрузки игр идут через прокси. Если прокси с ограниченным трафиком, добавьте папку Steam кнопкой «+ Добавить программы» → «Папка...». Серверы Valve при включённой галочке «Игры Steam» идут напрямую в любом случае.
- DNS-запросы всех программ, в том числе исключённых, идут через прокси: Windows отправляет их от имени системной службы, а не программы.
- Трафик исключённых программ проходит через адаптер `singbox` и обрабатывается sing-box, хотя и уходит напрямую. Для Dota 2 это решает галочка «Игры Steam», а голосовая связь Discord может получить небольшую добавку к задержке.
- Kill switch не работает, как и в режиме «Весь компьютер». Если в списке ничего не отмечено, режим равен режиму «Весь компьютер».

## Режим «Весь компьютер»
- Через прокси идёт весь интернет-трафик компьютера, в том числе обновления Windows и облачные диски. Учитывайте это, если у прокси ограничен трафик.
- DNS-запросы идут через прокси на 1.1.1.1 по DNS over HTTPS, поэтому ваш провайдер их не видит. Адрес самого прокси-сервера определяется обычным DNS.
- Локальная сеть (роутер, принтеры, NAS) работает напрямую.
- С HTTP-прокси весь UDP и IPv6 отклоняются: звонки, часть игр и онлайн-сервисы на UDP работать не будут. Для них нужен SOCKS5-прокси с поддержкой UDP ASSOCIATE.
- Kill switch в этом режиме не работает: его фильтры привязаны к списку программ. Если sing-box упадёт, весь трафик пойдёт напрямую с вашим настоящим IP, а программа покажет уведомление. Включённый ранее kill switch при подключении в этом режиме снимается.
- Если прокси перестал отвечать при работающем sing-box, интернет пропадёт на всём компьютере. Нажмите «Отключить», чтобы вернуть прямое подключение.
- Перед переподключением в этом режиме sing-box сначала останавливается. Если новая проверка прокси не пройдёт, компьютер останется без прокси, и программа покажет причину.
- Выбор режима сохраняется в settings.json. Если прокси уже подключён, нажмите «Переподключить», чтобы применить его.

## iPhone
На iPhone прокси настраивается в бесплатном приложении **sing-box MT** из App Store (iOS 15 и новее). Это официальное приложение sing-box, тот же движок, что и в Proxy Manager. Прежнее приложение sing-box VT из App Store убрано.

Кнопка «Для iPhone» делает для него профиль с прокси из формы (тип, сервер, порт, логин, пароль): сохраняет файл `.json` и копирует его текст в буфер обмена. Перед сохранением профиль проверяется командой `sing-box check`. Дальше:
1. Установите sing-box MT.
2. Отправьте профиль себе в Telegram, в «Избранное»: вставьте текст или перетащите файл.
3. В sing-box MT создайте новый профиль типа Local и вставьте в редактор текст из Telegram. Можно и импортировать файл, если сохранить его на телефоне в «Файлы».
4. Выберите профиль и включите его. iOS попросит разрешение добавить конфигурацию VPN.

Что делает профиль:
- Через прокси идёт весь телефон: iOS не даёт выбирать программы, поэтому режима «Выбранные программы» на iPhone нет.
- Локальная сеть работает напрямую. DNS идёт через прокси (1.1.1.1 по DNS over HTTPS).
- С HTTP-прокси UDP и IPv6 отклоняются: звонки FaceTime, WhatsApp, Telegram и часть игр работать не будут. Для них нужен SOCKS5-прокси с поддержкой UDP.
- Kill switch из Proxy Manager на iPhone не переносится: если выключить профиль в sing-box MT, телефон пойдёт в сеть напрямую.

В профиле записан пароль от прокси открытым текстом. После импорта удалите сообщение в Telegram и сохранённый файл.

## Выбор программ
Программа узнаётся по полному пути к `.exe`, а не по имени: `chrome.exe` из другой папки (например, Chromium от Playwright или Gologin) через прокси не пойдёт. Пути ищутся при каждом подключении.
- **Claude** — приложение Claude для Windows и Claude Code. Приложение установлено как пакет Windows в `C:\Program Files\WindowsApps\Claude_<версия>_…`, и при каждом обновлении эта папка меняется, поэтому правило написано под любую версию: после обновления Claude переподключаться не нужно. Входят также папки данных приложения (`%LOCALAPPDATA%\Claude-Data` и папка пакета; туда оно скачивает собственный Claude Code), Claude Code из расширения VS Code (`.vscode\extensions\anthropic.claude-code-*`, а также Cursor и Windsurf) и Claude Code, установленный отдельно (`%USERPROFILE%\.local\bin\claude.exe`). Чтобы Claude Code работал в VS Code, галочка «VS Code» не обязательна.
  - Claude Code, установленный через npm, работает внутри `node.exe` и под это правило не попадает: добавьте `node.exe` кнопкой «+ Добавить программы» или поставьте Claude Code установщиком.
  - Сайт claude.ai в браузере идёт через прокси, только если отмечен сам браузер.
- **Google Chrome** — `chrome.exe` из папки установки Google Chrome (`...\Google\Chrome\Application\`); путь берётся из реестра и стандартных папок.
- **VS Code** — вся папка установки VS Code (берётся из реестра, стандартных папок или запущенного `Code.exe`) и все программы из папки расширений `%USERPROFILE%\.vscode\extensions`. Туда входят Claude Code (`claude.exe`) и Codex (`codex.exe`): они ходят в сеть отдельными процессами, а не через `Code.exe`.
- **Hermes** — все программы из папки `%LOCALAPPDATA%\hermes`. `Hermes.exe` из `hermes-agent\apps\desktop\release\win-unpacked` — только окно приложения: запросы к нейросетям делает фоновый процесс `hermes serve`, который работает на встроенном Python Hermes (`hermes\tools\python-…\python.exe`). Его встроенные node, Chromium, git и uv тоже лежат в этой папке и идут через прокси.
- **Свои программы** — кнопка «+ Добавить программы» открывает список программ с вашего рабочего стола и общего рабочего стола всех пользователей. Отметьте нужные и нажмите «Готово». Добавленные программы появляются в главном окне рядом с Claude, Google Chrome, VS Code и Hermes, каждая со своей галочкой, и остаются там при следующих запусках.
  - Галочка включает и выключает прокси для программы, не убирая её из списка. Крестик справа убирает программу из списка.
  - «Файл...» добавляет любой `.exe` или ярлык, «Папка...» — все программы из папки.
  - Для Discord, Slack и других программ, которые при обновлении переезжают в новую папку (`app-1.0.x`), добавляется вся их папка.
  - Игры Steam и других лаунчеров (ярлыки `.url`) и приложения из Microsoft Store в список с рабочего стола не попадают. Для игры нажмите «Файл...» и укажите её `.exe`.
  - Если программа работает через отдельный лаунчер и трафик всё равно идёт мимо прокси (например, Synology Drive), добавьте кнопкой «Папка...» папку программы.
  - Если добавленную программу потом удалили с компьютера, подключение не начнётся и назовёт её путь: снимите у неё галочку или уберите её из списка.
  - Программы из текстового поля прежних версий переносятся в список автоматически.
- Команды, запущенные во встроенном терминале VS Code (например, `claude`, `git`, `npm`), — это отдельные программы. Они не входят в группу VS Code; при необходимости добавьте их кнопкой «+ Добавить программы» → «Файл...». Так же и с Hermes: системные программы, которые агент запускает из папки Windows или Program Files (например, `powershell.exe`, `curl.exe`), в группу Hermes не входят.
- Список программ, галочки и режим сохраняются в settings.json и восстанавливаются при следующем запуске. Изменения применяются при следующем подключении: если прокси уже подключён, нажмите «Переподключить».

## Kill switch
Работает только в режиме «Выбранные программы». Галочка «Kill switch» (включена по умолчанию). Через Windows Filtering Platform — движок, на котором работает брандмауэр Windows, — выбранным программам запрещается выходить в интернет мимо TUN-интерфейса sing-box:
- пока sing-box работает, их трафик идёт через TUN и запрет его не касается;
- если sing-box упал, был убит или не запустился при переподключении, программы остаются без интернета, а не уходят в сеть с вашим настоящим IP;
- заодно закрывается утечка через WebRTC: браузер не может отправить пакет в интернет с адреса физического адаптера даже при работающем прокси;
- локальная сеть (192.168.x.x, 10.x.x.x и т. п.) остаётся доступной;
- запрет сохраняется после перезагрузки Windows: пока вы не нажмёте «Подключить» или «Отключить», выбранные программы без интернета. Это работает, даже если выключен брандмауэр Windows.

В WFP нельзя запретить папку целиком — только конкретные `.exe`. Поэтому для Hermes, VS Code и папок из «Других программ» список `.exe` собирается в фоне после подключения (это занимает от нескольких секунд до минуты) и кэшируется в `logs\programs-cache.json`. Кроме того, каждые 5 секунд в запрет добавляются только что запущенные программы из выбранных папок. Подключение от этого не замедляется: фильтры ставятся и снимаются одной транзакцией за доли секунды.

Пока kill switch держит программы без интернета, статус в окне — «Нет прокси — программы заблокированы», значок в трее красный. Чтобы вернуть прокси, нажмите «Подключить». Чтобы программы снова ходили напрямую, нажмите «Отключить» — kill switch снимется. Фильтры видны командой `netsh wfp show filters` (в имени — «Proxy Manager kill switch»).

## Отключение и выход
- Кнопка «Отключить» останавливает sing-box и снимает kill switch: программы снова ходят в сеть напрямую.
- Пока прокси подключён, кнопка «Подключить» называется «Переподключить»: она перезапускает sing-box с текущими настройками.
- Закрытие окна прячет программу в трей.
- Пункт «Выход» останавливает sing-box, снимает kill switch и завершает программу.
- Если sing-box не удаётся остановить, приложение покажет ошибку и останется открытым. PID sing-box сохраняется для восстановления туннеля после аварийного закрытия приложения: при следующем запуске программа подхватит работающий sing-box.
- Повторный запуск программы, пока она уже работает, просто открывает её окно.

## Логи
- `logs\sing-box.log` — лог sing-box. По умолчанию в него пишутся только предупреждения и ошибки. Чтобы видеть каждое соединение и путь программы, которая его открыла, добавьте в settings.json `"verbose_log": true` и переподключитесь; учтите, что такой лог растёт примерно на 10 МБ в час.
- Если лог больше 5 МБ, при подключении он переименовывается в `sing-box.old.log`, и начинается новый.
- `logs\app.log` — внутренние ошибки самой программы.
- `logs\programs-cache.json` и `logs\kill-switch-state.json` — найденные `.exe` и список программ под kill switch.
- Кнопка «Открыть лог» открывает лог sing-box.

## Важные ограничения
- Это стартовый проект, а не проверенная на всех сетевых конфигурациях VPN-замена.
- Если kill switch выключен, при аварийном завершении sing-box трафик выбранных программ пойдёт напрямую. С kill switch защищены все `.exe`, найденные в выбранных папках при последнем сканировании, и всё, что из них запускалось; программа, которая появилась в папке после сканирования и впервые запущена при упавшем sing-box, может успеть выйти в сеть напрямую до 5 секунд, пока Proxy Manager её не заметит.
- HTTP-прокси работает через HTTP CONNECT и не передаёт UDP. В HTTP-режиме UDP выбранных программ отклоняется, чтобы браузеры переключались с QUIC на TCP; UDP-зависимые функции выбранных программ (например, звонки) через прокси работать не будут. Остальные программы это не затрагивает. Для SOCKS5 UDP сервер должен поддерживать UDP ASSOCIATE.
- В режиме выбранных программ DNS-запросы всех программ, включая выбранные, идут на DNS-серверы вашего сетевого адаптера напрямую, а не через прокси. Адреса сайтов, к которым обращаются выбранные программы, видны вашему DNS-провайдеру. DNS работает только по IPv4.
- Программа распознаётся по пути к `.exe`. Если программа ходит в сеть через вспомогательный процесс из другой папки, добавьте его `.exe` или папку в список программ.
- Текущая проверка IP проверяет внешний адрес только через HTTPS-запрос; это не полноценный аудит утечек DNS/IPv6.
- Пароль сохраняется в settings.json открытым текстом. Не используйте на общем компьютере; для постоянного использования перенесите секрет в Windows Credential Manager.
- Перед использованием обновите sing-box до актуальной стабильной версии и проверьте конфиг командой:
  `bin\sing-box.exe check -c configs\proxy.json`
- При ошибке смотрите `logs\sing-box.log` и `logs\app.log`.

## Устранение неполадок
- «Не найден sing-box.exe»: проверьте путь `bin\sing-box.exe`.
- «Сервер не отвечает как HTTP-прокси / SOCKS5-прокси»: выбран не тот тип прокси или порт. У многих провайдеров HTTP и SOCKS5 работают на разных портах.
- «Прокси отклонил логин или пароль»: проверьте учётные данные в личном кабинете провайдера. Некоторые провайдеры авторизуют по IP-адресу и не проверяют пароль вовсе.
- «Не ответил за 8 секунд» или «отклонил подключение»: прокси недоступен из вашей сети, или указан неверный адрес или порт.
- Ошибка конфигурации: выполните команду проверки из раздела выше и проверьте лог.
- `configure tun interface: ... already exists / Element not found / device ... is not functioning`: Windows не успела удалить TUN-адаптер прошлого запуска sing-box — так бывает, если sing-box был убит, а не остановлен (через Диспетчер задач, `taskkill /F`, при аварии). Proxy Manager останавливает sing-box мягко (Ctrl+Break), а при такой ошибке сам повторяет запуск до 3 раз.
- Нет доступа к интернету: отключите sing-box, проверьте доступность прокси-сервера и совместимость его UDP.
- Окно не появляется: запустите программу ещё раз — откроется окно уже запущенного экземпляра. Или найдите значок в области уведомлений Windows.
- Программа закрылась без сообщения: смотрите `logs\app.log`.
