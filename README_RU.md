# Proxy Manager (Windows)

Небольшой GUI для запуска sing-box с SOCKS5 outbound через TUN.

## Что умеет
- Подключение через SOCKS5 или HTTP-прокси (IP, порт, логин, пароль).
- Запуск и остановка sing-box.
- Проверка внешнего IPv4 через api.ipify.org.
- Сворачивание окна в системный трей.
- Раздельное сохранение настроек HTTP и SOCKS5 в settings.json с переключением профилей.

## Требования
- Windows 10/11 x64.
- Python 3.11 или новее.
- Права администратора для TUN/маршрутов.
- Windows amd64 версия sing-box.
- SOCKS5- или HTTP-прокси с доступом из вашей сети. HTTP-прокси не передаёт UDP; SOCKS5-серверу для UDP-зависимых приложений нужна поддержка UDP ASSOCIATE.

## Установка
1. Распакуйте архив в `D:\Oleg\ProxyManager` или другую папку без ограничений доступа.
2. Скачайте официальный Windows amd64 архив sing-box: https://github.com/SagerNet/sing-box/releases
3. Поместите `sing-box.exe` в `bin\sing-box.exe`.
4. Откройте PowerShell в папке проекта:
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python main.py
   ```
5. При запросе UAC разрешите запуск от имени администратора.
6. Выберите тип прокси, введите IP/домен, порт, логин и пароль, нажмите «Подключить».
7. Сверьте внешний IP до и после подключения.
8. TUN направляет браузерный трафик через выбранный профиль автоматически. Не задавайте отдельный прокси в настройках Chrome, Edge или Firefox. Для HTTP-профиля IPv6 и UDP блокируются, так как HTTP-прокси поддерживает только TCP.

## Отключение и выход
- Кнопка «Отключить» останавливает sing-box.
- Закрытие окна прячет программу в трей.
- Пункт «Выход» останавливает sing-box и завершает программу.
- Если sing-box не удаётся остановить, приложение покажет ошибку и останется открытым. PID sing-box сохраняется для восстановления туннеля после аварийного закрытия приложения.

## Важные ограничения
- Это стартовый проект, а не проверенная на всех сетевых конфигурациях VPN-замена.
- Без Kill Switch при аварийном завершении sing-box Windows может восстановить прямой маршрут. Не используйте это решение, если недопустим выход трафика напрямую.
- HTTP-прокси работает через HTTP CONNECT и не передаёт UDP. В HTTP-режиме DNS использует только IPv4, а UDP отклоняется в туннеле, чтобы браузеры переключались с QUIC на TCP; UDP-зависимые приложения (например, игры и звонки) работать не будут. Для SOCKS5 UDP сервер должен поддерживать UDP ASSOCIATE.
- Текущая проверка IP проверяет внешний адрес только через HTTPS-запрос; это не полноценный аудит утечек DNS/IPv6.
- Пароль сохраняется в settings.json открытым текстом. Не используйте на общем компьютере; для постоянного использования перенесите секрет в Windows Credential Manager.
- Перед использованием обновите sing-box до актуальной стабильной версии и проверьте конфиг командой:
  `bin\sing-box.exe check -c configs\proxy.json`
- При ошибке смотрите `logs\sing-box.log`.

## Устранение неполадок
- «Не найден sing-box.exe»: проверьте путь `bin\sing-box.exe`.
- Ошибка конфигурации: выполните команду проверки из раздела выше и проверьте лог.
- Нет доступа к интернету: отключите sing-box, проверьте доступность SOCKS5 сервера и совместимость его UDP.
- Окно не появляется: проверьте значок приложения в области уведомлений Windows.
